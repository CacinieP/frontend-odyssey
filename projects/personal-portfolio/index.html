01. About Me

Design-minded engineer with a love for web standards

I fell in love with frontend engineering when I realized that simple text files — HTML and CSS — can be viewed by billions of people across devices, cultures, and accessibility tools.

Before reaching for heavy JavaScript frameworks, I believe in squeezing every ounce of power from semantic HTML5 elements, modern CSS Grid and Flexbox, and fluid responsive design. Strong foundations produce faster pages, simpler codebases, and better user journeys.

When I'm not tweaking CSS variables or auditing color contrast ratios, you can find me mentoring aspiring developers, studying typography, or experimenting with design systems.

Guiding Principles

  • 🎯
    Accessibility First: Web content belongs to everyone regardless of ability or device.
  • ⚡
    Performance Obsessed: Lean markup and zero bloat mean lightning-fast load times.
  • 📐
    Systematic Styling: Token-driven custom properties for consistent design rhythms.
