## What is Frontend Odyssey?

Frontend Odyssey is a **free, open-source, hands-on** guide that takes you from writing your first HTML tag to building AI-powered applications — all using modern web technologies and TypeScript.

## Who is this for?

- **Complete beginners** who want to learn web development from scratch
- **Backend developers** who want to understand the frontend world
- **Frontend developers** who want to fill knowledge gaps and learn AI integration
- **Anyone** curious about building with AI in the browser

## How to use this guide

### 📖 Read the docs
Each chapter has clear explanations with real-world analogies. Concepts build on each other — we recommend following the order.

### 💻 Run the examples
Every concept comes with runnable code. Clone the repo and run:

```bash
git clone https://github.com/your-username/frontend-odyssey.git
cd frontend-odyssey
pnpm install
```

Each example is a standalone project:

```bash
cd examples/01-html/semantic-tags
pnpm dev
```

### 🏋️ Do the challenges
Test your understanding with coding challenges that come with automated tests:

```bash
cd challenges/01-html/challenge-01
pnpm test  # Tests will fail — make them pass!
```

### 🚀 Build the projects
Each section has a capstone project that puts everything together.

## The Learning Path

Every chapter answers a question you'll naturally ask after the previous one:

1. **HTML** — "What is a webpage?"
2. **CSS** — "How do I make it look good?"
3. **JavaScript** — "How do I make it interactive?"
4. **TypeScript** — "How do I catch errors before they run?"
5. **React** — "How do I build real applications?"
6. **Engineering** — "How do I work like a professional team?"
7. **AI Agents** — "How do I build intelligent applications?"
