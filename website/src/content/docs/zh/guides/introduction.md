## Frontend Odyssey 是什么？

Frontend Odyssey 是一份**免费、开源、动手实践**的指南，带你从写第一个 HTML 标签开始，一直到构建 AI 驱动的应用——全部使用现代 Web 技术和 TypeScript。

## 适合谁？

- **零基础初学者**：想从头学习 Web 开发的人
- **后端开发者**：想了解前端世界的人
- **前端开发者**：想补齐知识空白、学习 AI 集成的人
- **所有人**：对在浏览器中使用 AI 构建应用感到好奇的人

## 如何使用这份指南

### 📖 阅读文档
每一章都有清晰的讲解和现实世界的类比。概念之间层层递进——建议按顺序学习。

### 💻 运行示例
每个概念都配有可运行的代码。克隆仓库然后运行：

```bash
git clone https://github.com/CacinieP/frontend-odyssey.git
cd frontend-odyssey
pnpm install
```

每个示例都是独立的项目：

```bash
cd examples/01-html/semantic-tags
pnpm dev
```

### 🏋️ 完成挑战
通过带有自动化测试的编程挑战来检验你的理解：

```bash
cd challenges/01-html/challenge-01
pnpm test  # 测试会失败——你的任务是让它们通过！
```

### 🚀 构建项目
每个章节都有一个综合性项目，将所学内容融会贯通。

## 学习路径 (Learning Path)

每一章都在回答你在完成上一章后自然会产生的问题：

1. **HTML** — "网页是什么？"
2. **CSS** — "怎么让它好看？"
3. **JavaScript** — "怎么让它动起来？"
4. **TypeScript** — "怎么在运行前就捕获错误？"
5. **React** — "怎么构建真正的应用？"
6. **工程化 (Engineering)** — "怎么像专业团队一样开发？"
7. **AI 智能体 (AI Agents)** — "怎么构建智能应用？"
